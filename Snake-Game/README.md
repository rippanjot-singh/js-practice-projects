# Snake Game README

## Overview

A simple grid based snake game built with vanilla JavaScript, CSS, and HTML. The snake moves automatically on an interval. You control the direction with arrow keys, eat fruit to grow, and avoid crashing into walls or yourself.

## Features

* Dynamic 10x10 grid generated with JavaScript.
* Snake movement with arrow key controls.
* Fruit spawns randomly while avoiding snake body.
* Score and high score tracking using localStorage.
* Custom sound effects for eating, background music, and death.
* Game over detection with instant restart.

## How It Works

### Grid

A 100 cell grid is generated by looping and appending divs with the class `box`.

### Snake Logic

* Snake is stored as an array of indexes.
* Head moves based on `direction`.
* Collision detection for walls and self.
* Eating a fruit grows the snake instead of popping the tail.

### Fruit

`randomFruit()` selects a random free cell and marks it red.

### Scoring

Score is `(snake.length - 3) * 10`.
High score is saved to `localStorage.highscore`.

### Controls

* Arrow keys to move.
* First key press starts the game.
* Any key after game over restarts the game.

## Files Used

* Sound files located in `./public/sfx/`
* Image for snake head in `./public/img/`

## How To Run

1. Open the project folder.
2. Launch `index.html` in your browser.
3. Press any arrow key to start.
